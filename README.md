# Web Programming Jobsheet

Repository ini berisi kumpulan tugas dan praktikum **Web Programming** yang dikerjakan sebagai bagian dari kegiatan perkuliahan.

## 📚 Deskripsi

Project ini digunakan untuk mendokumentasikan hasil pengerjaan jobsheet Web Programming, mulai dari konsep dasar hingga implementasi berbagai teknologi web.

Materi yang terdapat dalam repository ini meliputi:

* HTML
* CSS
* JavaScript

## 🛠️ Teknologi yang Digunakan

* **HTML5** — Struktur halaman web
* **CSS** — Styling dan layout
* **JavaScript** — Interaksi dan logika pada halaman web

## 📁 Struktur Repository

```text
Repository-Web-Programming/
├── Jobsheet-01/
├── Jobsheet-02/
├── Jobsheet-03/
├── Jobsheet-04/
├── ...
└── README.md
```

Setiap folder jobsheet berisi source code dan file pendukung yang digunakan dalam pengerjaan materi tersebut.

## 🚀 Cara Menjalankan

1. Clone repository:

```bash
git clone [URL_REPOSITORY]
```

2. Masuk ke folder repository:

```bash
cd [NAMA_REPOSITORY]
```

3. Buka folder jobsheet yang ingin dijalankan.

4. Jalankan file `index.html` menggunakan browser.
   
## 📄 Catatan

Repository ini dibuat untuk keperluan **pembelajaran dan perkuliahan**.
